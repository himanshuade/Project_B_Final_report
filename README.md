# ATP Tennis Match Prediction

**Author:** Himanshu Muley (A1895211)

## Overview
Comparing logistic regression, Elo ratings, and hybrid models 
for predicting ATP tennis match outcomes (2000–2019).

## Files
- `tennis_prediction_combined.Rmd` — Full analysis with all 12 models
- `data/` — ATP match data files (Sackmann, 2023)

## How to Run
1. Open `tennis_prediction_combined.Rmd` in RStudio
2. Ensure the `data/` folder contains ATP match CSVs
3. Knit the document

## Data Source
Sackmann, J. (2023). Tennis ATP Match Data.
